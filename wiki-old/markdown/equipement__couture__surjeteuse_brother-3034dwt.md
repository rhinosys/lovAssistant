# Surjeteuse Brother 3034DWT
![image](https://www.brother.eu/-/media/product-images/supplies/sewing-and-craft/overlockers/3034dwt/3034dwt_main.png)

## Machine :
  - surjeteuse 3 et 4 fils ; 
  - coupe du tissus juste avant le surjet ;
  - rapide (> 100 points / minute) ;
  - mise en place des fils "aisée" (en vrai pas facile, mais il suffit de suivre les chiffres, en commençant par la bonne bobine => Cf manuel ci-après).

![image](https://www.brother.eu/-/media/product-images/supplies/sewing-and-craft/overlockers/3034dwt/3034dwt_4_colour_easy_threading_guide.png)

### Accessoires :
  - pied fronceur ;
  - pied passepoil ;
  - pied pour point invisible ;
  - bac à déchets ;
  - table d'extension.

#### Également inclus :
  - pochette pour accessoires ;
  - pinces ;
  - filet ;
  - disque bloque-bobine ;
  - tournevis hexagonal ;
  - jeu d'aiguilles ;
  - housse de protection ;
  - pédale ;
  - DVD d'instructions.
